# 05. 첫 30일 실행표

목표는 매출이 아니라 **첫 구독 1건 + 진단 30건 발송**입니다.
판매 순서는 항상 **무료 진단 → 온보딩 → 구독** 입니다.
하루 2시간 기준으로 짰습니다.

## 1주차 — 존재 만들기

| 일 | 할 일 | 소요 |
|---|---|---|
| 1 | 브랜드 지메일 생성 / 오픈채팅방 개설 / `{{ }}` 자리 전부 채우기 | 1h |
| 1 | `landing.html` GitHub Pages 배포 (`deploy.ps1` 흐름 그대로 씀) | 1h |
| 2 | 랜딩에 FAQ 스키마·구조화 데이터 심고 검증 — **내 랜딩이 첫 시연물** | 2h |
| 3 | 크몽 전문가 등록, 활동명 "인용연구소", 프로필 작성 | 2h |
| 4 | 크몽 서비스 3종 등록 — 진단 9만 / 온보딩 90만 / Growth 79만 (`03-카피` §1) + 심사 제출 | 2h |
| 5 | 타깃 리스트 30곳 수집 (블로그 운영 중인 회사, 스프레드시트) | 2h |
| 6 | 진단 3건 실행 → 아웃리치 메일 3통 발송 | 3h |
| 7 | 진단 스크립트 초안 (ld+json 파싱 + robots 확인) | 2h |

**1주차 끝 상태**: 랜딩 살아있음, 크몽 심사 중, 메일 3통 나감.

## 2주차 — 아웃리치 본격화

| 일 | 할 일 |
|---|---|
| 8~12 | **매일 진단 2건 + 메일 2통** (주 10건) |
| 9 | 디스콰이엇 글 업로드 (`03-카피` §2) |
| 11 | 커리어리 포스트 (a) 게시 |
| 13 | 블로그 1편 실험 시작 — A/B 글 2개 발행, 관측 시작 |
| 14 | 1차 회고: 메일 13통 중 회신 몇 건? 문구 어디서 끊겼나? |

**회신이 0건이면** 메일 문제입니다. 콜드메일에서 고칠 순서:
① 제목이 광고처럼 보임 → 진단 결과를 제목에 넣기
② 구체적 수치 없음 → "경쟁사는 3회 인용, 귀사 0회" 처럼 숫자로
③ 대상이 틀림 → 블로그 자체가 부실한 곳은 제외

## 3주차 — 첫 계약 만들기

| 일 | 할 일 |
|---|---|
| 15~19 | 매일 진단 2건 + 메일 2통 (누적 ~25건) |
| 16 | 회신 온 곳과 상담 → **온보딩 반값 제안, 구독 첫 달까지 묶어서. 대신 익명 케이스 스터디 사용 동의** |
| 18 | 커리어리 포스트 (b) |
| 20 | 진단 스크립트 자동화 완성 → 건당 시간 절반으로 |
| 21 | 크몽 첫 주문 없으면 최저가 상품 가격·썸네일 조정 |

## 4주차 — 신뢰 자산 쌓기

| 일 | 할 일 |
|---|---|
| 22~26 | 진단 계속 + **첫 고객사 작업 실행** |
| 24 | 블로그 실험 중간 결과 발행 |
| 25 | 커리어리 포스트 (c) / 오픈채팅방 3곳 참여 |
| 27 | 첫 고객사 전/후 인용 비교 → **익명 케이스 스터디 작성** |
| 28 | 케이스 스터디를 랜딩·크몽·디스콰이엇에 반영 |
| 29~30 | 30일 회고 + 다음 달 계획 |

## 30일 후 점검 기준

| 지표 | 최소선 | 잘한 편 |
|---|---|---|
| 진단 발송 | 20건 | 40건 |
| 회신 | 3건 | 8건 |
| 상담 | 2건 | 5건 |
| 구독 개시 | 1건 | 2~3건 |
| 월 반복 매출(MRR) | 39만원 | 120만원+ |
| 케이스 스터디 | 1건 | 2건 |

**구독 0건이어도 진단 30건 + 콘텐츠 5편이 쌓였다면 실패가 아닙니다.**
2개월차부터 인바운드가 붙기 시작합니다. 1개월차에 그만두는 게 진짜 실패입니다.

## 반대로, 이건 하지 마세요

- 랜딩 디자인 일주일 다듬기 → 아무도 안 봅니다. 아웃리치가 트래픽을 만듭니다.
- 가격표 완성될 때까지 영업 미루기 → 첫 3건은 어차피 협상으로 정해집니다.
- 상품 라인 5개 만들기 → 하나(진단)만 팔고 나머지는 상담에서 꺼내세요.
- 플랜별로 기능 잠그기 → 1인 운영에서 기능 분기는 유지보수 지옥입니다. 발행량으로만 나누세요.
- 유료 광고 → 리드당 단가가 대행 마진을 넘습니다. 레퍼런스 생긴 다음에 고려하세요.
