## §1. 크몽 서비스 등록

**서비스 제목** (한 줄, 검색어를 다 태웁니다)
```
ChatGPT·Perplexity에 우리 브랜드가 인용되게 만듭니다 | AEO·GEO 최적화 + 스키마 실제 적용
```

**요약**
```
진단 리포트만 드리지 않습니다. AI가 읽는 형태로 사이트에 직접 반영해 드립니다.
FAQ·구조화 데이터 자동 삽입 파이프라인을 만들어 온 현직 엔지니어가 작업합니다.
```

**상세 설명**
```
■ 이런 분께 필요합니다

· 블로그에 글은 쌓여 있는데 ChatGPT에 물어보면 경쟁사만 나옵니다
· AI 검색 대응을 해야 한다는 건 아는데, 뭘 고쳐야 하는지 모르겠습니다
· 대행사 진단 리포트를 받았지만 "그래서 누가 적용하죠?" 에서 멈췄습니다

■ 무엇이 다릅니까

대부분의 GEO 대행은 두 가지 중 하나입니다.
전략 문서를 주거나(적용은 고객사 몫), 원고를 대량으로 주거나(구조는 손 안 댐).

저는 그 사이의 빈 칸을 채웁니다.
원고에서 문답을 추출해 FAQPage 스키마로 만들고, BlogPosting 구조를 정리하고,
메타·퍼머링크·카테고리까지 채워 발행되는 라인을 직접 깝니다.
콘텐츠 발행 자동화를 실제로 구축·운영해 온 엔지니어가 작업합니다.

■ 작업 범위

[1] AI 인용 진단
    핵심 질의 5개 × ChatGPT / Perplexity / Gemini / Claude
    인용 여부, 경쟁사 인용 현황, 누락 원인 3가지, 재현 가능한 질의문 제공

[2] 구조 정비
    스키마 재설계 (BlogPosting · FAQPage · Organization · Breadcrumb)
    기존 상위 20개 글 구조 개편 — FAQ 신설, 헤딩 재편, 답변 문단 선두 배치
    Rank Math 전 항목 세팅 / 인덱싱·크롤러 접근 정리

[3] 인용 운영 (월간)
    질의 의도 기반 AEO 원고 발행 + 스키마 자동 삽입 + 월간 인용 리포트

[4] 파이프라인 구축
    노션 콘텐츠 플래너 → 워드프레스 자동 발행 라인 구축 및 인수인계
    대행을 끊어도 사내에 남는 자산입니다

■ 진행 방식

주문 → 사이트·경쟁사 정보 수신 → 진단 (2일) → 결과 리뷰 → 작업 (7~10일) → 전/후 인용 테스트

■ 약속하지 않는 것

"AI 검색 1위 보장" 같은 말은 하지 않습니다.
AI 답변에는 순위가 없고, 그런 걸 보장한다는 곳은 근거 없이 말하는 겁니다.
대신 작업 전후의 인용 결과를 같은 질의문으로 재현 가능하게 보여드립니다.

■ 상담

채팅으로 사이트 주소만 주시면 무료로 1차 진단해 드립니다.
```

**패키지 구성**
| | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 이름 | 인용 진단 리포트 | 구조 정비 | 인용 운영 1개월 |
| 가격 | 90,000원 | 1,800,000원 | 1,290,000원 |

## §3. 커리어리 / X — 짧은 포스트 3종

**(a) 문제 제기**
```
"우리 블로그 글 300개 있는데 ChatGPT는 왜 경쟁사만 인용하죠?"

이 질문을 요즘 자주 받습니다. 답은 대개 셋 중 하나입니다.

1. 답이 글 맨 아래 있습니다 — AI는 앞 문단을 봅니다
2. FAQ 섹션이 사람 눈에만 FAQ입니다 — FAQPage 스키마가 없으면 기계에겐 그냥 문단입니다
3. 질문 형태의 제목이 하나도 없습니다 — 사람들이 AI에 묻는 방식과 글 제목이 안 맞습니다

글을 더 쓰기 전에 있는 글부터 고치는 게 훨씬 빠릅니다.
```

**(b) 방법론**
```
AEO 글쓰기에서 제일 효과 큰 습관 하나만 고르라면: 결론을 첫 문단에 쓰는 것.

기승전결로 쓰면 사람은 끝까지 읽지만 AI는 앞부분만 인용합니다.
"~에 대해 알아보겠습니다"로 시작하는 글은 인용될 문장이 없습니다.

제목이 질문이면, 첫 문단이 그 답이어야 합니다. 근거는 그 다음입니다.
```

**(c) 신뢰 쌓기**
```
GEO 대행 알아보실 때 이것만 물어보세요.

"작업 후에 인용됐는지 어떻게 확인하나요?"

여기서 스크린샷만 준다고 하면 거르세요.
AI 답변은 매번 달라져서 스크린샷은 증거가 안 됩니다.
쓴 질의문을 그대로 주고, 직접 돌려보게 하는 곳을 고르세요.
```

## §6. 블로그 글 1편 개요 (첫 글로 바로 쓰세요)

**제목**: FAQ 스키마 하나로 AI 인용률이 달라지는가 — 30일 A/B 기록

**구성**
1. 첫 문단에 결론부터 (AEO 원칙 자체를 시연)
2. 실험 설계: 같은 주제 글 2개, 한쪽만 FAQPage 스키마 적용
3. 측정: 질의 20개 × 엔진 4종 × 주 1회 = 320회 관측, **질의문 전문 공개**
4. 결과 표 + 예상 밖이었던 것
5. 한계: 표본 적음, 엔진 업데이트 영향 배제 못 함 — **이걸 쓰는 게 신뢰를 만듭니다**
6. 끝에 한 줄: "같은 방식으로 진단해 드립니다" + 링크

한계와 실패를 쓰는 익명 필자가, 성공만 쓰는 실명 필자보다 신뢰받습니다.
