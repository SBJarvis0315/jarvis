## §1. 크몽 서비스 등록

**서비스 제목** (한 줄, 검색어를 다 태웁니다)
```
AEO·GEO 콘텐츠 월 구독 | ChatGPT 인용되는 글을 매달 자동 발행해 드립니다
```

**요약**
```
원고 승인만 하시면 스키마 생성부터 발행, 인용 추적까지 자동으로 돕니다.
건당 견적 없이 월정액 하나. 최소 약정 없고 언제든 해지하실 수 있습니다.
```

**상세 설명**
```
■ 이런 분께 필요합니다

· 블로그에 글은 쌓여 있는데 ChatGPT에 물어보면 경쟁사만 나옵니다
· AI 검색 대응을 해야 하는 건 아는데, 매달 누가 이걸 굴릴지가 문제입니다
· 대행사 진단 리포트를 받았지만 "그래서 누가 적용하죠?" 에서 멈췄습니다

■ 왜 구독인가

AEO는 한 번 손보고 끝나는 일이 아닙니다.
AI 엔진은 계속 바뀌고, 인용은 최신 문서 쪽으로 옮겨갑니다.
그래서 프로젝트가 아니라 매달 도는 라인으로 만들었습니다.

■ 무엇이 자동인가

고객사가 하는 일은 하나입니다. 원고 승인.

  주제 선정·원고 승인   ← 여기까지만 사람이 합니다
        ↓
  FAQ 추출 · 스키마 생성 (FAQPage / BlogPosting)
        ↓
  메타·퍼머링크·카테고리 세팅, 이미지 처리
        ↓
  매일 09:00 · 20:00 정시 발행 (실패 시 자동 복구·알림)
        ↓
  4개 엔진 인용 관측 → 월간 리포트 → 다음 달 주제 제안

이 라인을 실제로 구축·운영해 온 엔지니어가 만듭니다.

■ 플랜

  Starter   월 39만원   신규 4건 / 추적 질의 20개
  Growth    월 79만원   신규 8건 + 리라이팅 4건 / 질의 50개 / 경쟁사 점유율
  Scale     월 149만원  신규 16건 + 리라이팅 8건 / 질의 150개 / 도메인 3개

  온보딩 1회 90만원 — 발행 라인 연결, 스키마 정비, 기존 상위 20개 글 점검
  연 결제 시 2개월분 할인 / 초과 발행 건당 12만원

  스키마 자동 생성·발행 자동화·월간 리포트는 전 플랜 동일하게 들어갑니다.
  기능을 잠가두고 상위 플랜에서 풀어주는 방식은 쓰지 않습니다.

■ 구독 조건

  · 최소 약정 없음. 다음 결제일 전에 말씀하시면 그 달로 종료됩니다. 위약금 없습니다.
  · 원고·이미지·스키마·발행물은 전부 고객사 자산입니다. 해지해도 내려가지 않습니다.
  · 6개월 이상 구독하시면 발행 라인 전체를 무상으로 인계해 드립니다.
    코드와 인수인계 문서를 드리고, 사내에서 직접 운영하실 수 있습니다.

■ 약속하지 않는 것

"AI 검색 1위 보장" 같은 말은 하지 않습니다.
AI 답변에는 순위가 없고, 그런 걸 보장한다는 곳은 근거 없이 말하는 겁니다.
대신 등록하신 질의를 매달 같은 문장으로 관측해 결과를 나란히 놓아 드립니다.
질의문도 함께 드리니 직접 돌려서 확인하시면 됩니다.

■ 먼저 확인해보세요

구독 전에 무료 인용 진단을 드립니다.
질의 5개 × AI 4종으로 현재 인용 여부와 누락 원인을 정리해 드리고,
직접 고칠 수 있는 항목까지 적어드립니다. 보시고 구독하지 않으셔도 됩니다.

채팅으로 사이트 주소만 주시면 시작합니다.
```

**패키지 구성**
| | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 이름 | 인용 진단 리포트 | 온보딩 (구독 개시) | Growth 1개월 |
| 가격 | 90,000원 | 900,000원 | 790,000원 |
| 기간 | 3일 | 14일 | 30일 |

> 크몽은 자동 정기결제가 아니라 **매달 재주문** 구조로 굴러갑니다.
> 그래서 크몽은 *진단·온보딩을 파는 입구*로 쓰고, 구독 자체는 온보딩 후
> 메일·계좌이체(또는 세금계산서)로 옮겨 받는 편이 정산과 이탈 관리 모두 편합니다.
> 크몽 밖 거래를 유도하는 건 정책 위반이니, **크몽으로 들어온 건은 크몽 안에서 재주문**으로 유지하고
> 외부 유입만 직접 결제로 받으세요.

## §3. 커리어리 / X — 짧은 포스트 3종

**(a) 문제 제기**
```
"우리 블로그 글 300개 있는데 ChatGPT는 왜 경쟁사만 인용하죠?"

이 질문을 요즘 자주 받습니다. 답은 대개 셋 중 하나입니다.

1. 답이 글 맨 아래 있습니다 — AI는 앞 문단을 봅니다
2. FAQ 섹션이 사람 눈에만 FAQ입니다 — FAQPage 스키마가 없으면 기계에겐 그냥 문단입니다
3. 질문 형태의 제목이 하나도 없습니다 — 사람들이 AI에 묻는 방식과 글 제목이 안 맞습니다

글을 더 쓰기 전에 있는 글부터 고치는 게 훨씬 빠릅니다.
```

**(b) 방법론**
```
AEO 글쓰기에서 제일 효과 큰 습관 하나만 고르라면: 결론을 첫 문단에 쓰는 것.

기승전결로 쓰면 사람은 끝까지 읽지만 AI는 앞부분만 인용합니다.
"~에 대해 알아보겠습니다"로 시작하는 글은 인용될 문장이 없습니다.

제목이 질문이면, 첫 문단이 그 답이어야 합니다. 근거는 그 다음입니다.
```

**(c) 구독 각인**
```
GEO를 프로젝트로 하면 대개 6개월 뒤 원점입니다.

AI 엔진은 계속 바뀌고, 인용은 최신 문서 쪽으로 옮겨갑니다.
한 번 스키마 붙이고 끝내면, 그 사이 매달 글을 쌓은 경쟁사가 그 자리를 가져갑니다.

한 번에 20개 고치는 것보다 매달 4개씩 꾸준히 나가는 쪽이 1년 뒤 훨씬 앞섭니다.
지루한 게 맞고, 그래서 자동으로 돌게 만들어야 합니다.
```

**(d) 신뢰 쌓기**
```
GEO 대행 알아보실 때 이것만 물어보세요.

"작업 후에 인용됐는지 어떻게 확인하나요?"

여기서 스크린샷만 준다고 하면 거르세요.
AI 답변은 매번 달라져서 스크린샷은 증거가 안 됩니다.
쓴 질의문을 그대로 주고, 직접 돌려보게 하는 곳을 고르세요.
```

## §6. 블로그 글 1편 개요 (첫 글로 바로 쓰세요)

**제목**: FAQ 스키마 하나로 AI 인용률이 달라지는가 — 30일 A/B 기록

**구성**
1. 첫 문단에 결론부터 (AEO 원칙 자체를 시연)
2. 실험 설계: 같은 주제 글 2개, 한쪽만 FAQPage 스키마 적용
3. 측정: 질의 20개 × 엔진 4종 × 주 1회 = 320회 관측, **질의문 전문 공개**
4. 결과 표 + 예상 밖이었던 것
5. 한계: 표본 적음, 엔진 업데이트 영향 배제 못 함 — **이걸 쓰는 게 신뢰를 만듭니다**
6. 끝에 한 줄: "같은 방식으로 진단해 드립니다" + 링크

한계와 실패를 쓰는 익명 필자가, 성공만 쓰는 실명 필자보다 신뢰받습니다.
