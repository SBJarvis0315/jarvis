# 02. 채널 플레이북 — 어디에, 어떻게, 익명으로

## 익명 유지 실전 가이드 (먼저 읽으세요)

| 항목 | 방법 | 완전 익명 가능? |
|---|---|---|
| 이메일 | 브랜드용 지메일 신규 생성. 이름 필드에 "인용연구소" | ✅ |
| 상담 채널 | 카카오톡 **오픈채팅 1:1**. 프로필·실명 노출 없음 | ✅ |
| 전화 | 받지 마세요. "상담은 채팅/메일로만" 을 정책으로 명시 | ✅ |
| 랜딩 도메인 | 가비아·후이즈 등에서 **후이즈 정보 비공개** 옵션 필수 | ✅ |
| 크몽 | 활동명(닉네임)으로 노출. 제출한 실명·증빙은 의뢰인에게 공개되지 않음 | ✅ 표시상 |
| 숨고 | 활동명 노출, 다만 견적 후 통화 유도가 강함 → 채팅 고정 필요 | △ |
| 세금계산서 발행 | 사업자등록 시 **대표자 성명**이 계산서에 찍힘 | ❌ |
| 통신판매업 신고 | 대표자명·주소가 공시됨 | ❌ |
| 계좌 입금 | 예금주명 노출 | ❌ |

**결론**: *영업·마케팅 단계는 100% 익명이 가능하지만, 돈이 오가는 순간 실명은 드러납니다.* 이건 회피 대상이 아니라 설계 대상입니다.

권장 구조:
1. **1~3개월차**: 완전 익명으로 콘텐츠·진단 영업. 결제는 프리랜서 개인 대 개인(3.3% 원천징수)으로 소액만.
2. **레퍼런스 2~3건 확보 후**: 개인사업자 등록 + **상호를 "인용연구소"로** 등록. 이러면 계약서·계산서에 상호가 앞에 서고, 실명은 서류 안에만 남습니다. 사실상 이게 최선의 익명 상태입니다.
3. 주소 노출이 걱정되면 **비상주 공유오피스 주소**(월 2~3만원)를 사업장 주소로 씁니다.

## 채널 우선순위

### 🥇 1순위 — 지금 당장 (전환율 높음)

#### ① 크몽
국내 대행 거래의 기본값. 검색 유입이 알아서 들어옵니다.
- 서비스명에 **"AEO"와 "GEO"와 "ChatGPT"** 를 모두 넣으세요. 셋 다 각각 검색됩니다.
- 카테고리: 마케팅 > 검색광고/SEO
- 최저가 상품(9만원 "AI 인용 진단 리포트")을 하나 깔아서 **리뷰를 먼저 쌓으세요.** 크몽은 리뷰 0건이면 아무리 좋아도 안 팔립니다.
- **구독 판매 주의**: 크몽에는 자동 정기결제가 없어 매달 재주문 구조가 됩니다. 크몽 유입은 크몽 안에서 재주문으로 유지하고(외부 거래 유도는 정책 위반), 랜딩·아웃리치로 들어온 건만 직접 결제로 받으세요.
- 카피: `03-카피-복붙모음.md` §1

#### ② 무료 진단 콜드 아웃리치 ★ 가장 강력
익명 브랜드의 최대 약점은 신뢰인데, **먼저 공짜로 결과물을 주는 것**이 이걸 한 번에 뚫습니다.
- 대상: 자사 블로그 운영 중인 회사 하루 5곳
- 방법: 진단을 **먼저 해서** 메일에 결과 3줄을 박아 보냅니다. "무료로 해드릴게요"가 아니라 "해봤는데 이렇더라"입니다.
- 응답률 체감: 그냥 제안 메일 1~2% vs. 결과 첨부 10~20%
- 카피: `03-카피-복붙모음.md` §4

#### ③ 자체 랜딩 + 그 자체가 데모
`landing.html` 을 GitHub Pages로 띄우고, **그 페이지 자체를 AEO 최적화의 시연물로** 만듭니다.
FAQ 스키마·구조화 데이터가 박혀 있고, 실제로 AI가 인용하기 시작하면 그게 최고의 포트폴리오입니다.
- 랜딩에 "이 페이지의 스키마 보기" 링크를 넣으세요. 이게 다른 대행사가 못 하는 자랑입니다.

### 🥈 2순위 — 2주차부터 (신뢰 자산 축적)

#### ④ 브런치 / 자체 블로그 — 공개 실험 기록
익명 전문가가 신뢰를 얻는 유일한 방법은 **남들이 안 하는 실험을 공개하는 것**입니다.
글 주제 3개(바로 쓸 수 있는 것):
1. "FAQPage 스키마를 넣은 글과 안 넣은 글, ChatGPT 인용률을 30일간 비교했다"
2. "국내 사이트 100개의 구조화 데이터를 긁어봤더니 — GEO 준비도 실태"
3. "AI는 우리 글의 어디를 읽는가: 답변 문단 위치를 바꿔가며 측정한 기록"

숫자와 방법론이 있는 글 하나가 자기소개 100줄을 이깁니다.

#### ⑤ 디스콰이엇 (disquiet.io)
메이커 커뮤니티. 자기 홍보를 자연스럽게 받아주는 몇 안 되는 곳.
"AI 인용 진단 도구를 만들었습니다" 형태로 **제품처럼** 올리세요. 대행 광고로 올리면 묻힙니다.

#### ⑥ 커리어리
마케터·기획자 밀집. 짧은 인사이트 포스트 주 2회 → 프로필에 랜딩 링크.

### 🥉 3순위 — 여유 될 때

- **네이버 카페**: '마케팅 커뮤니티', '아이보스' — 홍보글은 즉시 삭제되니 **질문에 답변**하면서 존재감만 쌓으세요.
- **오픈채팅방**: "SEO", "마케터", "1인기업" 검색해서 5개 정도 상주. 홍보 금지방이 많으니 눈치껏.
- **숨고**: 요청서가 오면 응답. 다만 통화 유도와 저가 경쟁이 심해서 우선순위 낮음.
- **위시켓/프리모아**: "파이프라인 구축" 상품(350만원) 전용. 대행보다 개발 건으로 접근할 때만.
- **X(트위터)/LinkedIn**: 익명 계정으로 영문 GEO 담론에 참여. 국내 리드 전환은 느리지만 브랜드감이 붙습니다.

## 채널별 기대치 (현실적으로)

| 채널 | 첫 리드까지 | 월 예상 리드 (3개월차) |
|---|---|---|
| 무료 진단 아웃리치 | 3~7일 | 8~15건 |
| (구독 전환은 진단 → 온보딩 → 구독 순으로 넘어갑니다. 진단에서 바로 구독을 팔지 마세요.) | | |
| 크몽 | 2~4주 (리뷰 필요) | 3~8건 |
| 블로그/브런치 | 6~10주 | 2~5건 |
| 디스콰이엇·커리어리 | 2~4주 | 1~3건 |

**아웃리치가 전체 리드의 절반 이상을 만듭니다.** 나머지는 그걸 뒷받침하는 신뢰 장치입니다.
콘텐츠만 쓰면서 기다리는 게 1인 대행이 실패하는 1번 패턴입니다.
