> AI가 당신 브랜드를 **인용하게** 만듭니다.

이 폴더는 익명 1인 브랜드로 **AEO·GEO 콘텐츠 자동 발행 구독 서비스**를 시작하기 위한
실행 키트입니다. 전략 문서가 아니라 **복붙해서 바로 올리는 자료**로 만들었습니다.

상품 구조는 건당 견적이 아니라 **발행량으로 나눈 월정액**입니다.
온보딩 1회 90만원 + Starter 39 / Growth 79 / Scale 149만원(월).
최소 약정 없음, 산출물 전부 고객사 소유, 6개월 이상 구독 시 파이프라인 무상 인계.

## 시작하기 전에 딱 3개만 채우세요

문서 곳곳의 `{{ }}` 자리를 바꾸면 됩니다.

1. `{{문의메일}}` — **새로 만든 별도 지메일**. 기존 개인 메일은 절대 쓰지 마세요.
2. `{{오픈카톡}}` — 카카오톡 오픈채팅 1:1 링크 (실명·프로필 노출 없음)
3. `{{도메인}}` — 랜딩 주소. 도메인 사기 전이면 GitHub Pages 주소로 시작해도 충분합니다.

```bash
cd promo
grep -rn '{{' . | cut -d: -f1 | sort -u   # 채워야 할 파일 목록
```

## 첫 주 목표

매출이 아니라 **첫 구독 1건**입니다.
무료 진단 리포트 10건을 뿌려서 1곳을 온보딩 반값으로 잡고, 그 결과를 익명 케이스 스터디로 만드세요.
구독 상품은 고객 수보다 **유지 기간**이 매출을 만듭니다. 3개월 버티는 1곳이 한 달 쓰고 나가는 3곳보다 낫습니다.

판매 순서를 지키세요: **무료 진단 → 온보딩 → 구독.** 진단에서 바로 구독을 팔면 대부분 튕깁니다.
