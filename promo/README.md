전략 문서가 아니라 **복붙해서 바로 올리는 자료**로 만들었습니다.

## 시작하기 전에 딱 3개만 채우세요

문서 곳곳의 `{{ }}` 자리를 바꾸면 됩니다.

1. `{{문의메일}}` — **새로 만든 별도 지메일**. 기존 개인 메일은 절대 쓰지 마세요.
2. `{{오픈카톡}}` — 카카오톡 오픈채팅 1:1 링크 (실명·프로필 노출 없음)
3. `{{도메인}}` — 랜딩 주소. 도메인 사기 전이면 GitHub Pages 주소로 시작해도 충분합니다.

```bash
cd promo
grep -rn '{{' . | cut -d: -f1 | sort -u   # 채워야 할 파일 목록
```

## 첫 주 목표

매출이 아니라 **레퍼런스 1건**입니다.
무료 진단 리포트 10건을 뿌려서 1곳을 무료~반값으로 잡고, 그 결과를 익명 케이스 스터디로 만드는 것이
익명 브랜드가 신뢰를 사는 유일하게 빠른 길입니다.
