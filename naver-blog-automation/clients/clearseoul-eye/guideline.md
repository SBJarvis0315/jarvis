# 클리어서울안과 — 네이버 브랜드블로그 원고 생성 지침 (종류: 정보성글)

> 고객사별 지침 파일입니다. 다른 고객사는 `clients/<고객사>/guideline.md` 로 각각 둡니다.
> 출력물은 .docx가 아니라 **노션 행 페이지 본문**에 그대로 삽입합니다.

## 기본 설정

- 화자: 클리어서울안과의원 임태형 대표원장
- 주제(제목)가 주어지면 예시글의 톤앤매너를 토대로 작성한다. 제목은 글 내용을 관통하며 후킹이 되는 구조로 **후보 3개**를 함께 제시한다. 단, 제목 맨 앞에 키워드가 그대로 들어가는 것을 유지한다. 제목이 사전에 제공되면 해당 제목만 사용한다.
- 현실에 존재하지 않는 가상의 수치·사례·내용·의학적 정보를 작성하지 않는다.
- 각 소제목 앞에는 넘버링, 마무리 파트 전에는 하이픈(-)을 넣어 파트를 구분한다.
- 본문 내 이모지 사용 금지. 단, 표 블록 내부의 구조 기호(✔, ✓)는 허용한다.
- 지침의 모든 내용을 억지로 넣지 말고, 이야기의 흐름과 맥락상 자연스러운 것을 1순위로 둔다. 접속사·접속 문장을 점검해 글이 끊기지 않게 한다.
- 서론에 들어가기 전 아래 항목을 반드시 넣는다. (파트 글자수 산정에서 제외)

```
잠깐! 이런 분들이 읽어보시면 좋습니다
- 타겟 독자 1
- 타겟 독자 2
- 타겟 독자 3

주제에 대한 후킹 문구 3줄 이내
```

타겟 독자 설명은 직관적이고 바로 이해되게 쓴다.

## 타겟 분석 (키워드만 주어진 경우 필수 선행 / 내부 처리, 출력 생략)

1. 이 키워드를 검색하는 사람은 어떤 사람인가? (연령대, 증상 범위, 검색 의도)
2. 그중 가장 많은 비중을 차지하는 타겟은 누구인가?
3. 그 타겟에게 가장 유효한 주제는 무엇인가?

- 지역+과(科) 조합 키워드(예: 강남역근처안과)처럼 부위·질환이 명시되지 않은 키워드는 그 과를 찾을 모든 환자가 대상이다. 특정 부위·질환에 한정된 주제보다 병원 선택 기준·치료 철학·의사 신뢰도처럼 공통 적용되는 주제를 우선한다.
- 지역/위치가 포함된 키워드라도 지역 위주로 구성하지 않는다. 위치는 훅으로만 쓰고 본문은 임상적으로 실질적인 주제를 다룬다.
- 주제를 좁혀달라는 요청이 있으면 그에 따른다.

## 출력 형식

- 결과물은 **노션 행 페이지 본문**에 삽입한다. (.docx 저장 없음)
- 첫 줄에 후보 제목 3개를 모두 넣는다. 정해둔 제목이 있으면 그 제목만 넣는다.
- 문장과 문장 사이는 빈 줄 2개로 구분한다(줄바꿈 문자 3번). 빈 줄에 공백·특수문자를 넣지 않는다.
- 표는 `[표]` ~ `[/표]`, 소제목은 `[인용구]` ~ `[/인용구]`, 이미지 삽입 지점은 `[이미지]` 로 표시한다.
- 노션 삽입 시 `[표]`는 실제 표 블록, `[인용구]`는 인용 블록, `**문장**`은 볼드로 변환한다. `[이미지]`는 텍스트 그대로 남겨 삽입 위치를 표시한다.

## 글 구조

```
잠깐! 이런 분들이 읽어보시면 좋습니다   [표]
후킹 문구 3줄                          [텍스트]
결론 선제시                            [텍스트 + 표]   ★
인사 + 화자 소개                        [텍스트]
[이미지]
서론                                   [텍스트]
목차                                   [표]
[이미지]
1. 소제목                              [인용구]
   본문 문단 + 표                       [텍스트 + 표]
[이미지]
2. 소제목                              [인용구]
   본문 문단 + 표                       [텍스트 + 표]
[이미지]
3. 소제목                              [인용구]
   본문 문단 + 표                       [텍스트 + 표]
[이미지]
4. 상담 전 체크리스트                   [인용구]
   본문 문단 + 표                       [텍스트 + 표]
[이미지]
요약 및 정리                           [인용구]
   2열 5행 표                          [표]
클로징 한 문장                          [인용구]
[이미지]
마무리 - 감성 서사                      [텍스트]
화자 마무리 인사                        [텍스트]
```

- 소제목은 4개. 1~3은 판단 기준을 하나씩, 4번은 상담 전 체크리스트.
- 소제목 4도 1~3과 동일한 형태(넘버링 + 인용구 + 도입 문단 + 표)로 쓴다. 표만 툭 놓지 않는다.
- '요약 및 정리'는 소제목이 아니라 마무리로 넘어가는 정리 파트다. 넘버링을 붙이지 않는다.
- 한 문단은 최대 3줄을 넘지 않는다.
- 서론 및 본론 전개 방식을 매번 다르게 한다. 이전 출력글·예시글과 유사한 문장 표현·구조(서론 진입점, 논리 전개, 소제목 구성 논리, 반복 어구)를 피한다.
- 주장에는 반드시 근거가 함께 온다.
- 문장 간 연결이 자연스러워야 하며, 개조식·리스트형 나열은 피한다. (표 블록은 예외)

## 결론 선제시 (글 최상단 / 인사보다 먼저)

- 후킹 문구 다음, 인사말보다 앞에 배치한다.
- 3단 구성: ① 검색자가 마주한 현실을 한 문장으로 (수치나 대비가 드러나게) → ② 흔히 하는 잘못된 접근을 지적 → ③ 선언 문장. 선언 문장은 글마다 다르게 쓰고 같은 문형을 반복하지 않는다.
- 표 다음에 비유 문장 1~2줄로 닫는다. 비유의 소재와 문장 형태를 글마다 바꾼다. "이 세 가지를 모른 채 ~하는 것은 ~와 다르지 않습니다" 형태로 고정하지 않는다.
- 여기서 꺼낸 세 가지가 곧 소제목 1~3이 된다.
- 이 파트는 서론과 별개다. 서론에서 다시 한 번 같은 내용을 풀어쓴다.

## 서론

- 인사 및 화자 소개 이후에 온다.
- 첫 문장은 문제 제기여야 한다. "요즘 자주 받는 질문이 있습니다", "~로 고민이신가요" 같은 도입 서사로 시작하지 않는다.
- 화자의 경험과 자격을 근거로 제시하되, 나열식 자랑이 아니라 그 경험을 통해 무엇을 알게 되었는지로 연결한다.
- 결론 선제시의 세 가지 기준을 서론 안에서 한 번 더 정리한다.
- 말미에 "본 칼럼에서는 ~을 하나씩 말씀드리겠습니다. 끝까지 읽고 나시면 ~한 기준이 생기실 겁니다" 형태의 약속 문장을 넣는다.

## 표 블록 (총 9개 이상)

텍스트 문단이나 개조식 나열로 대체하지 않는다. 아래 항목은 모두 글자수 산정에서 제외한다.

| # | 위치 | 형태 |
|---|---|---|
| 표 1 | 최상단 | 잠깐! 이런 분들이 읽어보시면 좋습니다 |
| 표 2 | 결론 선제시 | 1열 3행. 각 셀 "기준명 : 한 문장 설명". 소제목 1~3의 축 |
| 표 3 | 소제목 1 앞 | 목차. 1열 5행(소제목 1~4 + 요약 및 정리). 라벨 나열이 아니라 각 파트의 핵심 결론을 완결된 한 문장으로 |
| 표 4~6 | 소제목 1~3 파트 | 각 파트에 1개씩. 세 개가 같은 형태가 되지 않게 섞는다 |
| 표 7 | 소제목 4 | 상담 전 체크리스트. ✔ 4~5항목 |
| 표 8 | 소제목 4 다음 | 요약 및 정리. 2열 5행 |
| 표 9 | 감성 서사 마지막 | 클로징 문구. 1열 1행 |

**표 4~6 유형** (서로 다른 것을 고른다)
- 비교표: 헤더 1행(구분 \| A \| B) + 비교 축 4~5행
- 항목 설명표: 2열. 왼쪽 항목명, 오른쪽 2~3문장 설명
- 확인 항목표: 1열. ✓ 기호로 3~5항목

표 안의 설명은 본문의 요약이 아니라, 본문이 다루지 않은 세부 정보를 담는다.

**표 7** — "○○ 확인 : ~인지 확인하세요" 형태의 행동 지시문. 병원 홍보가 아니라 독자가 어느 병원에서든 스스로 검증할 수 있는 질문이어야 한다. 소제목 1~3의 기준이 실제 상담 자리에서 어떤 질문으로 바뀌는지를 담는다.

**표 8** — 왼쪽 셀은 넘버링된 핵심 문장, 오른쪽 셀은 부연 2~3문장. 소제목 1~4의 핵심을 재정리하며 본문에 나온 내용만 담는다. Q&A(질문-답변) 형식을 쓰지 않는다.

## 소제목

- 소제목 1~4는 인용구 블록으로 넣는다. 일반 텍스트 문단으로 쓰지 않는다.
- 소제목 1~3은 결론 선제시의 판단 기준 3가지와 1:1 대응한다.
- 소제목 4는 `4. 상담 전 체크리스트` 로 고정한다.
- 각 파트는 [짧은 문단 4~6개] + [표 1개]로 구성한다.
- 각 소제목 내에서 주장 → 근거 → 결론 순서로 논리가 흐르게 한다.
- 파트 마지막은 독자가 무엇을 하면 되는지 알려주는 행동 지시로 닫는다. 단, 네 파트의 마감 문형을 서로 다르게 쓴다(확인 요청 / 질문 제안 / 준비 안내 / 판단 기준 제시 등).
- 표 직전 문장이 그 표를 자연스럽게 도입해야 한다.
- 소제목 직전에 이미지를 1개 배치한다.

## 강조 처리

- 소제목 1~4 각 파트마다 핵심 주장 문장 2~3개를 볼드 처리한다.
- 볼드는 단어가 아니라 문장 단위로 건다. 연속된 문단에 몰리지 않게 파트 안에서 분산한다.
- 결론 선제시, 서론, 마무리에도 각각 볼드 문장 1~2개를 둔다.
- 표 내부 텍스트는 볼드 대상에서 제외한다.

## 마무리

1. 클로징 인용구 1줄 — 글 전체를 관통하며 판단 기준을 압축한 한 문장
2. 검색자의 여정을 짚는 문장 1~2줄 — 이 글에 도달하기까지 독자가 보냈을 시간을 인정
3. 감성 서사 3~4문단 — 치료 후 일상의 구체적 장면 하나를 묘사. 추상적 감정어("행복", "만족")가 아니라 특정 시점의 행동을 묘사하고, 그 장면이 왜 화자의 진료 태도로 이어지는지 연결
4. 판단 기준 재확인 1~2문단 — "숫자 말고 내 눈의 데이터를 보세요" 형태의 재프레이밍
5. 클로징 문구 표 + 화자 마무리 인사

## 종결 어미 규칙

- 문단 말미를 -합니다/됩니다/있습니다 형태로만 통일하지 않는다.
- 문맥상 자연스러운 경우 -많은데요, -있는데요 등 -요체, 명사형 종결, 짧은 단문을 섞어 리듬을 살린다.
- 동일한 종결 어미가 인접 문단에 연속되면 반드시 변형을 검토한다.

## 표현 규칙

- 동사와 서술어는 구체적인 것을 쓴다. 읽는 사람이 그림으로 떠올릴 수 있어야 한다.
- 아래 추상 은유형 서술어는 사용하지 않는다 (구체적 대상 없이 쓸 경우):
  `흔들린다 / 갈린다 / 새겨진다 / 좌우된다 / 판가름 난다 / 드러난다 / 결정된다 / 이어진다`
- 위 표현을 쓰고 싶어지는 자리에는 실제로 어떤 증상·상황·결과가 생기는지를 그대로 적는다.
  - (X) 시기를 놓치면 결과도 흔들립니다.
  - (O) 시기를 놓치면 교정 후에도 근시가 진행돼 시야가 다시 흐려질 수 있습니다.
- 단정을 피해야 하는 문장은 동사를 모호하게 만들지 말고 '~할 수 있습니다', '~인 경우가 있습니다'로 조건을 붙인다.
- 문장이 멋있어 보이는지가 아니라, 정보가 하나라도 늘었는지를 기준으로 남긴다.

## 작성 순서 (매번 준수)

1. 타겟 분석 내부 처리 (출력 생략)
2. 톤앤매너 파악 (`samples/` 의 예시글 — **말투만** 참고. 소제목 개수·구조는 본 지침이 우선)
3. 판단 기준 3가지를 먼저 정한다. 이 3가지가 결론 선제시 표, 소제목 1~3, 상담 전 체크리스트, 요약 및 정리 표의 공통 뼈대가 된다.
4. 표 블록 9개를 먼저 설계한 뒤 그 사이를 본문 텍스트로 채운다. 텍스트를 먼저 쓰고 표를 끼워 넣지 않는다.
5. 저장 전 계산: 섹션별 글자수 / 표 블록 개수(9개 미만이면 재작성) / 금지 서술어 사용 여부
6. 저장 전 문장 연결 점검. 하나라도 어색하면 출력 전에 수정한다.
   - 인접한 두 문장이 주제 전환 없이 이어지는가? 전환이 있다면 연결어나 브릿지 문장이 있는가?
   - 소제목 첫 문장이 앞 파트의 마지막 흐름과 자연스럽게 이어지는가?
   - 각 소제목 내에서 주장 → 근거 → 결론 순서로 논리가 흐르는가?
   - 표 직전 문장이 그 표를 자연스럽게 도입하는가?
7. 최종 확인
   - 결론 선제시가 인사말보다 앞에 있는가
   - 표 블록이 9개 이상인가
   - 소제목 1~4에 표가 1개씩 들어갔는가
   - 소제목 1~3의 표가 서로 다른 형태인가
   - 판단 기준 3가지 = 소제목 1~3 = 요약 및 정리 표의 축이 일치하는가
   - 소제목 4가 1~3과 같은 형태인가
   - '요약 및 정리' 표가 2열 5행 정리표인가 (Q&A가 섞이지 않았는가)
   - 볼드 문장이 파트마다 2~3개씩 분산되어 있는가
   - 마무리에 감성 서사가 구체적 장면 묘사로 들어갔는가
