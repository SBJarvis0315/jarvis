# 클리어서울안과 — 네이버 브랜드블로그 원고 생성 지침 (종류: 논문글)

> 플래너의 `종류` 속성이 **논문글** 인 행에만 적용합니다.
> 정보성글과 구조·분량·표 규칙이 전혀 다르므로 두 지침을 섞지 않습니다.

## 기본 설정

- 화자: 클리어서울안과의원 임태형 대표원장
- 주제가 담긴 제목이 주어지면 예시글의 톤앤매너를 토대로 그 주제에 대한 의학적·전문적 정보글을 작성한다.
- **키워드만 주어진 경우**: 겹치는 단어는 한 번만 삽입해 직접 제목을 만든다. 키워드는 반드시 맨 앞에 넣고, 띄어쓰기는 제시된 그대로 유지한다.
  - 예: `라미네이트 무삭제`, `라미네이트 통증` → `라미네이트 무삭제, 통증 있을까? <의사 작성>`
- 키워드만 나열해 제목을 지어야 한다면 글 내용을 관통하며 후킹이 되는 구조로 **후보 3개**를 제시한다.
  - 후보 3개는 **형태가 서로 달라야 한다.** 의문형("~할까?"), 선언형("~입니다"), 조건형("~라면"), 고백형("~느낀 것들"), 경고형("~하면 안 되는 이유") 등을 섞는다.
  - `<의사 작성>` 같은 고정 태그는 후보 중 **최대 1개에만** 사용한다. 나머지는 태그 없이 제목 자체의 후킹력으로 승부한다.
  - 이 과정에서도 제목 맨 앞에 키워드가 그대로 들어가는 것을 유지한다.
- 제목이 사전에 제공되면 해당 제목만 사용한다.
- 현실에 존재하지 않는 가상의 수치·사례·내용·의학적 정보를 작성하지 않는다.
- 각 소제목 앞에는 넘버링, 마무리 파트 전에는 하이픈(-)을 넣어 파트를 구분한다.
- **키워드는 본문 내에 총 5번 삽입한다.** 맥락과 자연스러움을 해치지 않아야 하며, 띄어쓰기는 제시된 그대로 유지한다. 제목 후보에 들어간 키워드는 세지 않고, **본문 내 횟수만 5번**이어야 한다.
- 본문 내 이모지 사용을 금지한다.
- 지침의 모든 내용을 억지로 넣지 말고, 흐름과 맥락상 자연스러운 것을 1순위로 둔다. 접속사·연결 문장을 점검해 글이 끊기지 않게 한다.

## 논문 인용 규칙

- 실제로 참고할 수 있는 **논문 링크**, 논문에서 발췌한 **이미지를 삽입할 위치**, 이미지와 관련된 **부연설명**까지 함께 출력한다.
- 논문은 **전문을 별도 구독·가입 없이 확인할 수 있는 곳**에서만 찾는다. (PMC, 오픈액세스 저널 등)
- 존재하지 않는 가상의 링크, 본문과 관련 없는 링크를 넣지 않는다.
- **논문 관련 내용은 최소 3군데**가 들어가게 한다.

### Figure 안내 시 필수 규칙

- Figure 번호를 함께 안내하려면, 반드시 해당 논문 페이지를 fetch해 **Figure 캡션 텍스트에서 번호와 설명을 직접 확인한 후** 안내한다.
- fetch 결과에서 캡션을 찾지 못했거나 이미지 렌더링 여부가 불확실하면, Figure 번호를 단정하지 않고 **"논문 페이지에서 직접 확인해주세요"** 라고만 안내한다.
- 추측으로 Figure 번호를 안내하는 것은 어떤 경우에도 금지한다.

## 서론 앞 고정 블록

서론에 들어가기 전 아래 항목을 반드시 넣는다. (해당 내용은 파트 글자수로 책정하지 않고 예외로 둔다.)

```
잠깐! 이런 분들이 읽어보시면 좋습니다
- 타겟 독자 1
- 타겟 독자 2
- 타겟 독자 3

주제에 대한 후킹 문구 3줄 이내
```

타겟 독자 설명은 직관적이고 바로 이해되게 쓴다.

## 타겟 분석 (키워드만 주어진 경우 필수 선행 / 내부 처리, 출력 생략)

1. 이 키워드를 검색하는 사람은 어떤 사람인가? (연령대, 증상 범위, 검색 의도)
2. 그중 가장 많은 비중을 차지하는 타겟은 누구인가?
3. 그 타겟에게 가장 유효한 주제는 무엇인가?

- 지역+과(科) 조합 키워드(예: 노원정형외과, 범어동내과)처럼 부위·질환이 명시되지 않은 키워드는 그 과를 찾을 모든 환자가 대상이다. 특정 부위·질환에 한정된 주제보다 병원 선택 기준·치료 철학·의사 신뢰도처럼 공통 적용되는 주제를 우선한다.
- 주제를 좁혀달라는 별도 요청이 있으면 그에 따른다.

## 출력 형식

- 첫 줄에 후보 제목 3개를 모두 넣는다. 정해둔 제목이 있으면 그 제목을 넣는다.
- 문장과 문장 사이는 빈 줄 2개로 구분한다(줄바꿈 문자 3번). 빈 줄에 공백·특수문자를 넣지 않는다.

## 분량 (공백 제외)

| 파트 | 최소 |
|---|---|
| 서론 | 300자 |
| 소제목 1 | 450자 |
| 소제목 2 | 450자 |
| 소제목 3 | 450자 |
| 마무리 | 150자 |
| **총량** | **1600자 이상** |

- 초과는 괜찮다.
- 측정 방법: `text.replace(' ', '').replace('\n', '').replace('\t', '').replace('\r', '')`
- **논문에 대한 부연설명 및 출처는 글자수로 책정하지 않는다.**

## 글 구조

- 서론 → 소제목 1 → 소제목 2 → 소제목 3 → 마무리. **소제목은 반드시 3개까지만** 작성한다.
- 한 문단은 최대 3줄을 넘지 않는다.
- 서론 및 본론 전개 방식을 매번 다르게 한다. 이전 출력글·예시글과 유사한 패턴을 반복하지 않는다.
- 이전 출력글·예시글과 유사한 문장 표현·구조를 피한다.
- 주장에는 반드시 근거가 함께 제시되어야 한다.
- 문장 간 연결이 자연스럽게 흘러야 하며, 개조식·리스트형 나열은 피한다.

## 작성 순서 (매번 준수)

1. 타겟 분석 내부 처리 (출력 생략)
2. 톤앤매너 파악
   - 같은 세션에서 이미 예시글 파일을 읽었다면 그 분석 결과를 그대로 쓴다. 파일을 다시 열지 않는다.
   - 아직 읽은 적이 없다면 `samples/` 의 예시글을 열어 톤앤매너를 파악한다. 이후 재열람하지 않는다.
3. python 스크립트 안에서 초안 텍스트를 변수로 작성한다.
4. 파일 저장 전, 동일 스크립트 내에서 **섹션별 글자수 + 키워드 횟수 + 주요 단어 빈도**를 즉시 계산한다.
5. 미달 또는 15회 초과 항목이 있으면 저장 전 동일 스크립트 안에서 보완한 뒤 저장한다.

> 규칙으로 못 박아두지 않으면 사고가 조용히 지나갑니다. 불필요하면 이 절만 지우시면 됩니다.

## A. 논문 링크 검증 사다리

링크를 0개로 두는 것과 검증 없이 넣는 것 둘 다 금지합니다. 아래 순서로 처리합니다.

1. WebSearch로 후보 논문을 찾는다. **오픈액세스 도메인 우선** — `pmc.ncbi.nlm.nih.gov`, `ncbi.nlm.nih.gov/pmc`, `doaj.org`, 학회지 자체 오픈액세스 페이지
2. WebFetch로 실제로 열리는지, 본문 문장과 내용이 관련 있는지 확인한다
3. 프록시 차단·403으로 fetch가 막히면 도메인 한정 재검색으로 교차 검증한 뒤 삽입하고, **"발행 전 접속 확인 권장"** 을 부연설명에 표기한다
4. 1~3이 모두 실패한 링크만 「확인 필요」로 남긴다

**금지 출처**: 타 병·의원 홈페이지/블로그, 커뮤니티·카페, 광고성 기사, 위키, 초록만 보이고 전문이 유료인 페이지

## B. 논문 인용 표기 형식

각 인용 지점에 아래를 함께 적습니다. 사람이 검수할 때 논문을 다시 찾지 않아도 되게 하기 위함입니다.

```
[논문 N]
- 제목 :
- 저널 / 연도 :
- 링크 :
- 이 글에서 쓰는 내용 : (한 문장)
- 이미지 삽입 위치 : (본문 어느 문단 뒤인지)
- 이미지 부연설명 : (2~3문장, 독자가 그림을 안 봐도 이해되게)
```

## C. 인용 문장의 단정 회피

논문 결과는 그 연구 조건에서의 결과이지 모든 환자에게 적용되는 사실이 아닙니다.

- (X) 스마일라식은 건조증이 생기지 않습니다.
- (O) 해당 연구에서는 수술 6개월 시점의 눈물막 지표가 수술 전 수준으로 회복됐다고 보고합니다.

연구를 근거로 쓸 때는 **연구명 또는 저널명을 문장에 명시**하고, 병원 자체 성과처럼 읽히지 않게 일반 의학 정보로만 서술합니다.

## D. 의료광고법 필터 (통과 필수)

- `최고`, `완치`, `100%`, `부작용 없음`, `국내 유일`, `1위` 등 최상급·단정 표현 금지
- 경쟁 병·의원 언급 금지
- 치료 전후 비교로 효과를 단정하는 서술 금지
- 참고자료에 없는 브랜드 수치(케이스 수·연혁·장비)는 만들지 않고 「확인 필요」 표시

## E. 표현 규칙 (정보성글 지침과 공유)

아래 추상 은유형 서술어는 구체적 대상 없이 쓰지 않습니다.

`흔들린다 / 갈린다 / 새겨진다 / 좌우된다 / 판가름 난다 / 드러난다 / 결정된다 / 이어진다`

쓰고 싶어지는 자리에는 실제로 어떤 증상·상황·결과가 생기는지를 그대로 적습니다.

## F. 종결 어미

문단 말미를 -합니다/됩니다/있습니다로만 통일하지 않습니다. -인데요, -있는데요 등 -요체와 명사형 종결, 짧은 단문을 섞어 리듬을 살리고, 동일 어미가 인접 문단에 연속되면 변형을 검토합니다.

## G. 저장 전 자동 점검 항목

`tools/check.py --mode paper` 가 아래를 검사합니다. 하나라도 걸리면 저장하지 않고 보완합니다.

- 섹션별 글자수 (서론 300 / 소제목 1~3 각 450 / 마무리 150 / 총 1600)
- 본문 키워드 정확히 5회 (제목 줄 제외)
- 주요 단어 15회 초과 여부
- 소제목 개수가 정확히 3개인지
- 논문 인용 블록 3개 이상
- 금지 서술어·최상급 표현·이모지
