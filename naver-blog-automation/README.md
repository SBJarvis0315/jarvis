# 네이버 브랜드블로그 원고 자동화

노션 콘텐츠 플래너를 읽어, 조건에 맞는 행마다 네이버 블로그 원고를 생성하고
해당 행 페이지 본문에 삽입한 뒤 진행 상황을 바꾸는 작업의 자산 저장소입니다.

## 대상 행 조건

플래너에서 아래를 **모두** 만족하는 행만 처리합니다.

- `담당자` 에 **이선우** 태그
- `키워드` 속성에 텍스트 있음
- `진행 상황` = **작성 전**
- `종류` 에 해당하는 지침이 `clients/<고객사>/guideline.md` 에 존재

## 처리 절차

1. `clients/<고객사>/guideline.md` (원고 생성 지침) + `reference.txt` (병원·원장 정보) + `samples/` (톤앤매너 예시글) 을 읽는다.
2. 행의 `키워드` 를 메인 키워드로 원고를 생성한다. 제목 맨 앞에 키워드를 그대로 둔다.
3. 저장 전 `tools/check.py` 로 파트별 글자수·표 개수·금지 서술어·이모지를 검증한다. 하나라도 미달이면 보강 후 재검증한다.
4. 검증을 통과한 원고를 **행 페이지 본문 끝**에 삽입한다. 기존 내용은 지우지 않는다.
5. 삽입에 성공한 행만 `진행 상황` 을 **원고 저장 완료** 로 바꾼다. 실패한 행은 상태를 건드리지 않는다.

## 디렉터리

```
clients/<고객사>/guideline.md   원고 생성 지침 (고객사마다 다름)
clients/<고객사>/reference.txt  병원·원장 정보, 말투, 시술 목록, FAQ
clients/<고객사>/samples/       톤앤매너 참고용 기존 발행글
drafts/                        생성된 원고 (노션 삽입 전 검토용)
tools/check.py                 지침 준수 자동 검증기
```

## 검증기 사용법

파트 경계는 `<<파트명>> ... <</파트명>>` 마커로 표시한 초안 파일에 대해 실행합니다.
마커는 최종 출력 시 제거됩니다.

```bash
python3 naver-blog-automation/tools/check.py <초안파일> [--emit 최종파일]
```

## 현재 상태

- 클리어서울안과 / 종류 `정보성글` — 지침 확보, 원고 1건 생성 완료
- 클리어서울안과 / 종류 `논문글` — **지침 미확보. 대기**
- 플래너 DB — 연결된 노션 워크스페이스(Lead-Gen Lab)에서 검색되지 않음. URL 확인 필요
