# 워드프레스 자동 발행

노션 플래너를 확인해 발행 조건을 만족한 원고를 워드프레스에 올리고,
Rank Math 설정까지 채운 뒤 플래너를 '게재완료'로 되돌려 씁니다.

## 실행 방법

작업 디렉터리는 `notion-wp-publish/` 입니다.

```bash
cd notion-wp-publish
PYTHONPATH=src python3 -m notionwp
```

고객사 설정은 노션 '고객사 설정표'에서 읽습니다. 상태가 '활성'이고 워드프레스 주소가
적힌 고객사를 **한 번의 실행으로 전부** 처리하므로, 고객사마다 따로 돌릴 필요가 없습니다.
한 곳만 돌리려면 `--client 클리어톤` 처럼 이름 일부를 넘기세요.

모드가 넷 있습니다. 확신이 없으면 안전한 쪽을 고르세요.

| 플래그 | 동작 |
|---|---|
| `--dry-run` | 조건 판정만. 워드프레스·노션 아무것도 건드리지 않음 |
| `--prepare DIR` | 이미지를 내려받고 `plan.json` 생성. 아무것도 발행하지 않음 |
| `--plan DIR --draft` | 검수한 ALT로 초안 생성. **공개하지 않음**, 노션도 그대로 |
| `--plan DIR` | 공개 발행 + 노션 게재완료·URL 기록 |

`--config 파일.json` 은 설정표를 거치지 않는 예외 경로입니다. 표에 없는 대상을 임시로
돌릴 때만 쓰고, 평소에는 쓰지 마세요.

## 표준 절차 — ALT는 이미지를 직접 보고 씁니다

**발행 요청을 받으면 아래 세 단계를 순서대로 진행하세요.** 곧바로 발행하지 마세요.

### 1단계 — 준비

```bash
cd notion-wp-publish
PYTHONPATH=src python3 -m notionwp --prepare work/
```

발행 조건을 통과한 원고의 이미지를 `work/<페이지ID>/images/` 에 내려받고
`work/<페이지ID>/plan.json` 을 만듭니다. `images[].alt` 는 비어 있습니다.

### 2단계 — 이미지를 보고 ALT 작성 (당신이 할 일)

각 `plan.json` 을 열고, `images[]` 의 **`preview` 경로를 Read 도구로 하나씩 열어
실제로 보세요.** 그런 다음 `alt` 를 채우고 파일을 저장합니다.

ALT를 쓸 때:

- **이미지에 실제로 보이는 것**을 쓰세요. 추측하거나 지어내지 마세요.
- `sections` 의 `heading` 과 `excerpt` 를 읽고, **그 이미지가 놓일 구간의 내용과
  맞물리게** 쓰세요. 같은 장비 사진이라도 어느 섹션에 놓이느냐에 따라 달라집니다.
- 한국어로 **20~50자 내외**. `이미지`, `사진`, `~하는 모습입니다` 같은 군더더기는 뺍니다.
- 키워드를 억지로 넣지 마세요. 검색엔진이 이미지를 이해하도록 돕는 설명문입니다.
- **의료 광고 규정**: 치료 전후 비교나 효과를 단정하는 표현은 쓰지 마세요.
  ("기미가 옅어진 피부" ❌ → "색소 레이저 시술 장비" ⭕)
- `hint` 가 있으면 원고를 쓴 에이전트가 그 자리에 의도한 그림입니다. 참고는 하되,
  **실제 이미지와 다르면 이미지 쪽을 따르세요.** hint 는 이미지가 업로드되기 전에
  쓰인 것이라 어긋날 수 있습니다.
- 이미지가 명백히 다른 섹션에 속하면 `anchor` 를 그 섹션의 값으로 바꿔도 됩니다.
  (`sections[].anchor` 참고) 특별한 이유가 없으면 기본값을 그대로 두세요 —
  원고 마커 위치이거나, 마커가 없으면 이미 글 전체에 고르게 배분된 값입니다.
- `thumbnail_preview` 도 열어보고 `thumbnail_alt` 를 채우세요. 비워두면 메타타이틀이 들어갑니다.
- **숏폼은 `images` 가 비어 있는 게 정상입니다.** 썸네일 한 장이 대표 이미지이면서 본문 맨 위에도
  들어가므로, `thumbnail_alt` 만 쓰면 됩니다. 설정의 `render.hero_image_types` 에 해당하는 유형입니다.

ALT가 하나라도 비어 있으면 3단계가 거부합니다.

#### 유튜브 영상 고르기 (있을 때만)

`plan.json` 에 `video_candidates` 가 채워져 있으면, 고객사 채널의 영상 목록입니다.
원고 주제와 맞는 영상이 있으면 하나만 골라 `video` 를 채우세요.

```jsonc
"video": {
  "url": "https://www.youtube.com/watch?v=...",
  "anchor": 23,                              // sections[].anchor 중 하나
  "note": "대표원장이 영상으로 직접 설명합니다"  // 영상 위 한 줄 안내
}
```

**고르는 기준은 주제 하나뿐입니다.**

- **주제가 맞으면 오래된 영상이라도 넣습니다.** 게시일이 예전이라는 이유로
  거르지 마세요. 2년 전 영상이라도 그 글에 맞으면 그게 맞는 영상입니다.
- **맞는 것이 여러 개면 그중 가장 최신을 고릅니다.** 후보 목록은 이미 최신순으로
  정렬되어 있으니, 조건에 맞는 것 중 위에 있는 것을 집으면 됩니다.
- **맞는 영상이 없으면 `video` 를 그대로 비워두세요.** 주제가 어긋나는 영상을
  억지로 붙이는 것보다 없는 편이 낫습니다.
- 제목만 보고 판단합니다. 비슷해 보여도 다루는 내용이 다르면 고르지 마세요.
  ("기미 레이저 횟수" 글에 "기미 악화시키는 습관" 영상은 어긋납니다)
- **한 편만** 넣습니다. 여러 개 넣지 않습니다.
- 위치는 그 영상이 설명하는 내용을 다루는 H2 섹션의 `anchor` 로 잡습니다.
  마땅한 자리가 없으면 `anchor` 를 `-1` 로 두면 글 중반에 들어갑니다.
- `video_candidates` 가 비어 있으면 그 고객사는 채널이 등록되지 않은 것입니다.
  그냥 넘어가세요.

### 3단계 — 발행

```bash
PYTHONPATH=src python3 -m notionwp --plan work/ --draft
```

**처음 돌리는 원고는 반드시 `--draft` 를 붙이세요.** 사용자가 초안을 확인하고
"발행해도 좋다"고 한 뒤에 `--draft` 를 빼고 다시 돌립니다. 그러면 새 글이 생기지 않고
그 초안이 그대로 공개됩니다.

> `--prepare` 로 이미지를 이미 받아뒀기 때문에, 3단계는 노션 첨부 주소(1시간 만료)를
> 다시 부르지 않습니다. 2단계에 시간이 걸려도 안전합니다.

## 인자 해석

사용자가 고객사 이름을 말하면 `--client` 로 넘기세요 (예: "클리어톤" → `--client 클리어톤`).
지정이 없으면 설정표의 활성 고객사를 전부 처리합니다.

- "확인만", "미리보기" → `--dry-run` 만 돌리고 끝냅니다
- "임시저장", "초안으로", "발행하지 말고", "테스트" → 3단계 절차 + `--draft`
- "발행해줘" → 3단계 절차 + `--draft` 로 먼저 보여주고 **승인을 받은 뒤** 공개

**애매하면 실발행하지 말고 물어보세요.** 공개는 되돌리기 어렵습니다.

`--draft` 로 돌린 뒤에는 편집 링크를 그대로 전하고, 작성한 ALT 목록도 함께 보여주세요.
확인이 끝나면 `--draft` 없이 다시 돌리면 그 초안이 공개된다는 점을 알려주세요.

## 결과 보고

명령이 끝나면 요약이 출력됩니다. 그대로 옮기지 말고 아래 형식으로 정리해서 보고하세요.

- **발행된 원고**: 제목과 링크
- **실패한 원고**: 제목과 원인, 그리고 사람이 무엇을 해야 하는지
- **조건 미달로 대기 중인 원고**: 어떤 항목이 비어 있는지
  (아직 '컨펌 진행 중'이 아닌 행은 정상이므로 보고하지 않아도 됩니다)

발행이 0건이고 대기 중인 원고도 없으면 "발행 대상 없음" 한 줄로 끝내세요.

노션 '자동화 실행 로그' DB에는 **스크립트가 알아서 한 줄을 남깁니다**(단계 = 워드프레스 발행).
직접 로그 행을 만들지 마세요. 두 줄이 됩니다.

## 실패했을 때

실패한 행은 플래너에서 자동으로 **'발행 오류'** 상태가 됩니다.
아래는 자주 나오는 원인과 대처입니다.

| 메시지 | 원인 | 대처 |
|---|---|---|
| `발행 대상 고객사가 없습니다` | 설정표에 활성 행이 없거나 워드프레스 주소가 빔 | 설정표의 상태·워드프레스 주소 확인 |
| `mu-plugin 을 찾을 수 없습니다` | 워드프레스에 브리지 플러그인 미설치 | `wp-mu-plugin/` 의 플러그인을 설치 (README 1-① 참고) |
| `환경변수가 비어 있습니다` | 토큰 미설정 | README의 '환경변수' 항목 참고 |
| `워드프레스에 '…' 분류가 없습니다` | 플래너 카테고리 이름이 워드프레스와 다름 | 메시지에 실제 분류 목록이 나옵니다. 플래너 옵션을 그 이름으로 고치고 재실행 |
| `슬러그 … 가 이미 사용 중입니다` | 같은 슬러그의 글이 이미 있음 | 플래너에서 슬러그를 바꾼 뒤 상태를 '컨펌 진행 중'으로 되돌리기 |
| `이미지를 내려받지 못했습니다` | 노션 첨부 주소 만료(1시간) | 그대로 재실행하면 새 주소를 받아옵니다 |
| `발행할 원고가 없음` | 페이지에 본문이 없거나 콘텐츠 가이드 토글만 있음 | 원고 작성 여부 확인 |
| 영상 후보가 0개 | 설정표에 유튜브 채널 미등록, 또는 조회 실패 | 발행은 정상 진행됩니다. 채널을 넣으려면 설정표에 추가 |

**중복 발행은 걱정하지 않아도 됩니다.** 워드프레스 글에 노션 페이지 ID가 각인되어
있어서, 같은 원고를 두 번 올리지 않습니다. 실패한 건을 고친 뒤 그냥 다시 돌리면 됩니다.

## 하지 말아야 할 것

- 발행 조건을 임의로 완화하지 마세요. 6개 조건은 전부 만족해야 합니다.
- 스크립트를 우회해 손으로 워드프레스 API를 직접 호출하지 마세요.
  Rank Math 설정과 노션 되돌려 쓰기가 누락됩니다.
- 원고 본문을 임의로 고쳐 발행하지 마세요. 수정이 필요하면 노션에서 고칩니다.
