# 워드프레스 자동 발행

노션 플래너를 확인해 발행 조건을 만족한 원고를 워드프레스에 올리고,
Rank Math 설정까지 채운 뒤 플래너를 '게재완료'로 되돌려 씁니다.

## 실행 방법

작업 디렉터리는 `notion-wp-publish/` 입니다.

```bash
cd notion-wp-publish
PYTHONPATH=src python3 -m notionwp --config config/cleartone.json
```

**먼저 `--dry-run` 을 붙여 한 번 확인하세요.** 어떤 원고가 조건을 통과하는지만
보여주고 실제로는 아무것도 건드리지 않습니다.

```bash
PYTHONPATH=src python3 -m notionwp --config config/cleartone.json --dry-run
```

고객사가 여러 곳이면 `config/` 안의 설정 파일마다 한 번씩 돌립니다.

## 인자 해석

사용자가 고객사 이름을 말하면 그에 맞는 설정 파일을 고르세요
(예: "클리어톤" → `config/cleartone.json`). 지정이 없으면 `config/` 의
모든 설정을 순서대로 실행합니다.

"확인만", "미리보기", "테스트" 같은 말이 있으면 `--dry-run` 을 붙입니다.

## 결과 보고

명령이 끝나면 요약이 출력됩니다. 그대로 옮기지 말고 아래 형식으로 정리해서 보고하세요.

- **발행된 원고**: 제목과 링크
- **실패한 원고**: 제목과 원인, 그리고 사람이 무엇을 해야 하는지
- **조건 미달로 대기 중인 원고**: 어떤 항목이 비어 있는지
  (아직 '컨펌 진행 중'이 아닌 행은 정상이므로 보고하지 않아도 됩니다)

발행이 0건이고 대기 중인 원고도 없으면 "발행 대상 없음" 한 줄로 끝내세요.

## 실패했을 때

실패한 행은 플래너에서 자동으로 **'발행 오류'** 상태가 됩니다.
아래는 자주 나오는 원인과 대처입니다.

| 메시지 | 원인 | 대처 |
|---|---|---|
| `mu-plugin 을 찾을 수 없습니다` | 워드프레스에 브리지 플러그인 미설치 | `wp-mu-plugin/` 의 플러그인을 설치 (README 1-① 참고) |
| `환경변수가 비어 있습니다` | 토큰 미설정 | README의 '환경변수' 항목 참고 |
| `슬러그 … 가 이미 사용 중입니다` | 같은 슬러그의 글이 이미 있음 | 플래너에서 슬러그를 바꾼 뒤 상태를 '컨펌 진행 중'으로 되돌리기 |
| `이미지를 내려받지 못했습니다` | 노션 첨부 주소 만료(1시간) | 그대로 재실행하면 새 주소를 받아옵니다 |
| `발행할 원고가 없음` | 페이지에 본문이 없거나 콘텐츠 가이드 토글만 있음 | 원고 작성 여부 확인 |

**중복 발행은 걱정하지 않아도 됩니다.** 워드프레스 글에 노션 페이지 ID가 각인되어
있어서, 같은 원고를 두 번 올리지 않습니다. 실패한 건을 고친 뒤 그냥 다시 돌리면 됩니다.

## 하지 말아야 할 것

- 발행 조건을 임의로 완화하지 마세요. 6개 조건은 전부 만족해야 합니다.
- 스크립트를 우회해 손으로 워드프레스 API를 직접 호출하지 마세요.
  Rank Math 설정과 노션 되돌려 쓰기가 누락됩니다.
- 원고 본문을 임의로 고쳐 발행하지 마세요. 수정이 필요하면 노션에서 고칩니다.
