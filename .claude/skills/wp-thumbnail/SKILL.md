# 썸네일 자동 생성

플래너를 훑어 썸네일이 없는 행에 이미지를 만들어 붙입니다. 워드프레스는
건드리지 않으므로 **원고 생성만 하는 고객사도 함께 처리합니다.**

## 실행 방법

작업 디렉터리는 `notion-wp-publish/` 입니다.

```bash
cd notion-wp-publish
PYTHONPATH=src python3 -m notionwp --thumbnails
```

| 플래그 | 동작 |
|---|---|
| `--dry-run` | 만들어보기만 하고 노션에 붙이지 않음 |
| `--client 클리어톤` | 그 고객사만 |
| `--skip 이름` | 그 고객사를 건너뜀. 여러 번 쓸 수 있음 |

## 어떤 행에 만드는가

세 조건을 **모두** 만족하는 행만 처리합니다.

1. **유형이 숏폼** — 당장은 숏폼만 만듭니다
2. **제목이 있고 '템플릿'이 들어 있지 않음** — 제목이 템플릿 이름 그대로면
   원고 생성이 아직 안 돌았거나 실패한 것이므로 건너뜁니다
3. **썸네일 칸이 비어 있음** — 사람이 올린 것을 절대 덮어쓰지 않습니다

이미 붙어 있는 썸네일은 손대지 않습니다. 다시 만들고 싶으면 사람이 플래너에서
파일을 지우고 다시 돌리면 됩니다.

## 디자인은 고객사마다 고정되어 있습니다

`notion-wp-publish/designs/<고객사>.json` 에 색·서체·로고가 적혀 있고,
스크립트는 그 파일만 읽습니다. **같은 고객사는 늘 같은 모습이 나옵니다.**

**이미 있는 디자인 파일을 다시 만들지 마세요.** 실행할 때마다 색을 다시 정하면
그 고객사 썸네일이 조금씩 달라집니다. 고쳐야 하면 파일을 직접 고칩니다.

### 디자인이 없는 고객사가 나오면 (당신이 할 일)

`'○○' 의 확정된 썸네일 디자인이 없습니다` 오류가 나면, 그 고객사 디자인을
한 번 정해서 굳혀야 합니다. 사람에게 물어보지 말고 직접 판단하세요.
마음에 안 들면 사용자가 말해 줄 것이고, 그때 파일만 고치면 됩니다.

**1단계 — 브랜드를 파악합니다.** 아래 순서로 근거를 찾습니다.

- 그 고객사 **로고 이미지**. 홈페이지에서 받아 직접 열어보세요. 색을 알아내는
  가장 확실한 근거입니다
- 노션의 **그 고객사 참고자료 페이지**. 홈페이지 주소·영문명·브랜드 톤이
  적혀 있습니다. 사이트가 허용 도메인에 없어 막히면 여기가 유일한 근거입니다
- 홈페이지 HTML

> **HTML에서 색을 기계적으로 뽑지 마세요.** 실제로 해 보면 카카오톡 상담 버튼
> 초록색이나 워드프레스 기본 팔레트 파랑이 나옵니다. 브랜드와 무관합니다.
> 반드시 로고를 눈으로 보거나 참고자료의 브랜드 정의를 읽고 정하세요.

**2단계 — 색을 정합니다.** 열 가지 색이 필요하지만 규칙은 단순합니다.

- 브랜드가 진한 색이면 그 색을 **배경**에 깔고 글씨를 밝게
- 밝은 색이면 아주 옅게 깔고 글씨를 진하게
- `accent`(상단 바)는 브랜드 색의 선명한 버전
- 뱃지 글씨는 뱃지 배경과 **밝기 차가 나야** 합니다. 안 그러면 묻힙니다

기존 고객사 파일을 열어 값의 감을 잡으세요. 서로 확실히 달라 보여야 합니다.

**3단계 — 굳힙니다.**

```python
from notionwp.designs import Design, save
from notionwp.thumbnail import Palette

save(Design(
    client="고객사명",
    palette=Palette(background=..., accent=..., title=..., sub=...,
                    pill_bg=..., pill_fg=..., brand=..., muted=...,
                    rule=..., ornament=...),
    name_en="ENGLISH NAME",       # 없으면 빈 문자열
    domain="example.co.kr",
    logo=로고_바이트,              # 못 구했으면 생략 — 워드마크로 대신합니다
    note="무엇을 근거로 이렇게 정했는지. 나중에 볼 사람을 위해 적습니다.",
))
```

**4단계 — 한 장 뽑아 눈으로 확인하고**, 디자인 파일과 로고를 커밋합니다.

## 결과 보고

- **만든 것**: 제목 목록
- **실패한 것**: 제목과 원인
- 0건이면 "썸네일 대상 없음" 한 줄로 끝냅니다

0건은 흔하고 정상입니다. 숏폼 원고가 새로 생겨야 대상이 나옵니다.

## 실패했을 때

| 메시지 | 원인 | 대처 |
|---|---|---|
| `확정된 썸네일 디자인이 없습니다` | 그 고객사 디자인 미정 | 위 절차대로 정해서 굳히기 |
| `폰트를 찾지 못했습니다` | `assets/fonts/` 누락 | 저장소가 제대로 받아졌는지 확인 |
| `썸네일을 그릴 브라우저를 찾지 못했습니다` | Chromium 없음 | `CHROMIUM_PATH` 환경변수로 지정 |
| `파일을 올리지 못했습니다` | 노션 업로드 실패 | 그대로 재실행. 반복되면 토큰 확인 |

한 행이 실패해도 나머지 행은 계속 처리합니다.

## 하지 말아야 할 것

- **이미 있는 썸네일을 덮어쓰지 마세요.** 사람이 고른 이미지일 수 있습니다
- **이미 확정된 디자인을 다시 만들지 마세요.** 같은 고객사 썸네일이 달라집니다
- **조건을 임의로 완화하지 마세요.** 특히 제목에 '템플릿'이 든 행은 건너뜁니다
- 스크립트를 우회해 손으로 노션에 파일을 올리지 마세요
