# output-styles

한국어 출력 품질을 위한 Claude Code output-style 지침 파일입니다.

## 출처

- 원본: https://github.com/snflkd/fluent-korean (MIT License)
- 원본 경로: `plugins/fluent-korean/output-styles/`

플러그인(`/plugin install`)으로 설치하지 않고 파일을 직접 배치했습니다. 이 저장소는
Claude Code 웹 세션과 자동 루틴에서도 구동되는데, 원격 컨테이너는 세션이 끝나면
사라지므로 플러그인 설치 상태가 유지되지 않기 때문입니다.

## 구성

| 파일 | 용도 |
|---|---|
| `fluent-korean.md` | 코딩 지침을 유지합니다. 기본값으로 지정되어 있습니다. |
| `fluent-korean-not-coding.md` | 코딩 지침이 제거되어 있습니다. 코드를 변경하지 않는 작업에 사용합니다. |

기본값은 `.claude/settings.json`의 `outputStyle` 항목에서 지정합니다.
output-style은 시스템 프롬프트에 포함되므로, 값을 바꾼 뒤에는 새 세션을 시작하거나
`/clear`를 실행해야 반영됩니다.

## 원본과 다른 부분

두 파일 모두 본문 말미에 `## 세부 동작` 단락을 추가했습니다. 원본 README가 안내하는
선택 블록 중에서 이 저장소의 상황에 맞는 세 가지를 골라 넣은 것입니다.

1. 한국어로 출력되는 모든 결과물에 지침을 적용합니다. 워드프레스와 게시판에 발행되는
   원고 본문까지 지침이 적용되도록 하기 위한 조항입니다.
2. 별도 지침이 존재하는 산출물 유형은 제외합니다. 고객사별 문체 가이드를 보호합니다.
3. 출력 직전에 지침 준수 여부를 점검합니다. 사람이 확인하지 않는 자동 루틴에서
   교정률을 높이기 위한 조항입니다.

원본을 갱신할 때에는 이 단락이 사라지지 않도록 주의해주십시오.
