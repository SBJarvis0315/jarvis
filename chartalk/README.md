# 캐릭터톡 — AI 캐릭터 챗봇 사이트

케이브덕처럼 **AI 캐릭터와 롤플레이 대화**를 나누는 구독형 사이트입니다.
회원가입 → 캐릭터 탐색 → 대화 → 결제 → 매출 확인까지 실제로 돌아가는 상태로 만들어져 있습니다.

- 공식 캐릭터 8명이 기본 제공 (소꿉친구·조선 탐정·심야 DJ·길드 마스터·고양이·영어 튜터·재무 코치·우주선 AI)
- 유저가 직접 캐릭터를 만들어 공개 (라이트 플랜부터)
- 토스페이먼츠 자동결제(빌링키) 구독 + 충전팩
- **플랜별 월 API 원가 상한**으로 마진을 먼저 확보하는 구조
- 관리자 매출 대시보드에서 월 30만원 목표 달성률을 바로 확인

---

## 1. 빠르게 실행하기

```bash
cd chartalk
npm install
cp .env.example .env      # ANTHROPIC_API_KEY 를 채워 넣습니다
npm start                 # http://localhost:3000
```

키가 없어도 실행됩니다. `ANTHROPIC_API_KEY` 가 비어 있으면 **데모 모드**로, `TOSS_SECRET_KEY` 가 비어 있으면
**모의 결제 모드**로 동작해서 결제 흐름까지 전부 눌러볼 수 있습니다(실제 결제는 일어나지 않습니다).

```bash
npm test        # 33개 테스트 (단위 + 서버를 실제로 띄우는 통합 테스트)
npm run renew   # 정기결제 배치 (크론에 등록)
```

**처음 가입한 계정이 관리자**가 되어 `/admin` 매출 대시보드를 볼 수 있습니다.
(`ADMIN_EMAILS` 를 지정하면 그 계정들만 관리자입니다.)

## 2. 어떻게 월 30만원을 만드는가

### 목표 조합 (셋 중 아무거나)

| 조합 | 인원 | 월 매출 |
|---|---|---|
| 라이트만 | 31명 | 306,900원 |
| 라이트 20 + 프로 6 | 26명 | 317,400원 |
| 라이트 15 + 프로 8 | 23명 | 307,700원 |

### 단가와 원가 (기본 설정 기준, 환율 1,380원)

| 플랜 | 가격 | 사용 모델 | 메시지당 원가 | 월 원가 상한 | 제공 메시지 | 마진 |
|---|---|---|---|---|---|---|
| 무료 | 0원 | Haiku 4.5 | 약 5.7원 | 500원 | 약 88개 | 획득 비용 |
| 라이트 | 9,900원 | Sonnet 5 | 약 13.0원 | 3,000원 | 약 231개 | **70%** |
| 프로 | 19,900원 | Opus 5 | 약 38.6원 | 7,000원 | 약 181개 | **65%** |

31명이 라이트를 쓰면 매출 306,900원 · 원가 최대 93,000원 · **순이익 약 21만원**이 남습니다.
무료 회원 100명이 한도를 꽉 채워 써도 원가는 5만원이므로, 전환율 10%면 손익이 맞습니다.

### 마진이 먼저 지켜지는 이유

한도를 "메시지 개수"가 아니라 **실제 API 원가(원)** 로 관리합니다
(`src/quota.js`). 대화가 길어져 토큰이 늘어나든, 모델을 바꾸든,
한 사용자가 그 달에 태울 수 있는 원가는 `costCapKrw` 를 넘지 못합니다.
그래서 "많이 쓰는 헤비 유저 때문에 적자가 나는" 흔한 사고가 구조적으로 막혀 있습니다.

한도를 다 쓴 사용자는 이탈하지 않고 **충전팩**(3,900원 / 9,900원)을 살 수 있어, 헤비 유저가 오히려 추가 매출이 됩니다.

### 숫자 바꾸기

가격·원가 상한·모델은 전부 `.env` 로 조정합니다. 예를 들어 마진을 더 키우려면:

```
MODEL_PRO=claude-sonnet-5      # 프로도 Sonnet 으로 (원가 1/3)
LITE_COST_CAP_KRW=2000         # 라이트 한도를 낮춰 마진 80%
```

반대로 몰입감을 최우선으로 하려면 `MODEL_LITE=claude-opus-5` 로 올리고 상한을 조정하면 됩니다.
바꾼 뒤 `/admin` 의 마진 수치로 바로 확인할 수 있습니다.

## 3. 실제로 돈을 받으려면 (토스페이먼츠)

1. [토스페이먼츠](https://www.tosspayments.com) 가입 → 개발자센터에서 **클라이언트 키 / 시크릿 키** 발급
2. `.env` 에 `TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY` 입력
3. 상점 관리자에서 **자동결제(빌링) 사용**을 신청 (심사 필요)
4. `SITE_URL` 을 실제 도메인으로 설정 — 카드 등록 후 이 주소로 돌아옵니다
5. 정기결제 배치를 크론에 등록

```cron
5 3 * * * cd /srv/chartalk && npm run renew >> logs/renew.log 2>&1
```

결제 흐름은 이렇게 이어집니다.

```
/account 에서 플랜 선택
  → 토스 카드 등록창 (requestBillingAuth)
  → /billing/success 로 복귀 (authKey)
  → 서버가 빌링키 발급 + 첫 달 결제
  → 매일 03:05 배치가 만료된 구독을 자동 재결제
```

해지를 누르면 즉시 끊기지 않고 **기간 만료 시점에 해지**되며(`cancel_at_period_end`), 그 사이 언제든 되돌릴 수 있습니다.
결제 실패는 구독을 바로 없애지 않고 무료로 내려, 카드만 바꾸면 이어서 쓸 수 있게 했습니다.

> 사업자 등록 · 통신판매업 신고 · 전자상거래법상 표시사항(이용약관, 환불 규정, 개인정보처리방침)은
> 별도로 준비해야 합니다. 결제 대행사 심사에서도 요구합니다.

## 4. 구조

```
chartalk/
├─ src/
│  ├─ server.js        HTTP 서버 · 라우팅 · 세션
│  ├─ config.js        요금제 · 모델 요금표 · 원가 계산
│  ├─ db.js            SQLite 스키마 (node:sqlite, 네이티브 빌드 없음)
│  ├─ auth.js          scrypt 비밀번호 · 세션 쿠키
│  ├─ characters.js    캐릭터 CRUD · 시스템 프롬프트 조립 · 안전 규칙
│  ├─ seed.js          기본 제공 캐릭터 8명
│  ├─ claude.js        Claude 스트리밍 호출
│  ├─ quota.js         월 원가 한도 · 사용량 기록
│  ├─ billing.js       토스 빌링키 결제 · 충전 · 자동갱신
│  ├─ stats.js         매출 대시보드 집계
│  ├─ http.js          라우터 · SSE · 정적파일 · 요청 제한
│  ├─ routes/          core(계정·캐릭터) / chat(대화) / commerce(결제·관리자)
│  └─ jobs/renew.js    정기결제 배치
├─ public/             index · chat · create · account · admin
└─ test/               unit(25) + e2e(8)
```

의존성은 `@anthropic-ai/sdk` 하나뿐입니다. DB는 파일 하나(`data/chartalk.db`)라 백업이 곧 복사입니다.

### 대화가 만들어지는 과정

1. 캐릭터 설정 + 말투 + 상황 + 예시 대화 + **내 페르소나**를 시스템 프롬프트로 조립 (`characters.js`)
2. 최근 N턴만 잘라 Claude 에 전달 (플랜별 12~40턴 — 길수록 몰입감이 좋고 원가도 오릅니다)
3. 답변을 SSE 로 한 글자씩 화면에 흘림
4. 끝나면 실제 토큰 사용량으로 원가를 계산해 기록하고 남은 메시지 수를 갱신

모든 캐릭터에 공통 안전 규칙이 붙습니다 — 미성년자 성적 묘사 금지, 실존 인물 사칭 금지,
범죄·자해 방법 안내 금지, 자해 암시 시 상담 안내(109). 이 규칙은 캐릭터 설정보다 우선합니다.

## 5. 배포

Node 22.5 이상이면 어디든 올라갑니다. 가장 단순한 형태:

```bash
# 서버(예: 라이트세일·오라클 무료 인스턴스)에서
git clone <저장소> && cd chartalk && npm ci --omit=dev
cp .env.example .env && vi .env         # 키 입력, SITE_URL 을 도메인으로
NODE_ENV=production node --disable-warning=ExperimentalWarning src/server.js
```

앞단에 Caddy나 Nginx로 HTTPS를 붙이면 끝입니다(`NODE_ENV=production` 이면 세션 쿠키에 Secure 가 붙습니다).
프로세스 유지는 systemd 또는 pm2 를 쓰세요.

**운영 전 점검**

- [ ] `.env` 는 저장소에 올리지 않았는가 (`.gitignore` 에 포함되어 있습니다)
- [ ] `data/` 디렉터리 정기 백업
- [ ] Anthropic 콘솔에서 월 사용량 한도(spend limit) 설정 — 최후의 안전장치
- [ ] 이용약관 · 개인정보처리방침 · 환불 규정 페이지
- [ ] 결제 실패 알림을 받을 방법 (배치 로그 확인 또는 알림 연동)

## 6. 가입자를 모으는 순서

사이트가 아니라 **첫 30명**이 이 사업의 어려운 부분입니다. 이 저장소의 다른 도구
(`notion-wp-publish`)로 블로그를 자동 발행하고 있다면 그 채널을 그대로 유입구로 쓸 수 있습니다.

1. 캐릭터 하나를 주인공으로 삼은 대화 캡처를 X(트위터)·스레드에 올립니다. 캐릭터 챗 시장은 캡처가 곧 광고입니다.
2. 공식 캐릭터를 한 달에 2~3명씩 늘립니다. 새 캐릭터는 재방문 이유가 됩니다.
3. 유저가 만든 캐릭터가 인기를 얻으면 창작자에게 프로 플랜을 무료로 주세요. 콘텐츠가 콘텐츠를 부릅니다.
4. 무료 한도(88메시지)는 "재미를 알기엔 충분하고 계속 쓰기엔 모자란" 지점입니다. 전환율을 보며 `FREE_COST_CAP_KRW` 를 조정하세요.
5. `/admin` 의 유료 전환율과 원가 상위 사용자를 매주 확인하면 가격을 언제 올릴지 보입니다.
