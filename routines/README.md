바꾸기 전 상태를 여기에 남깁니다. aside(AI 브라우저)에서 도는 루틴도 같이 둡니다.

## 제안판에서 달라진 곳

품질에 영향이 없는 것만 넣었습니다. 원고 규칙·조건·금지사항은 그대로입니다.

1. **플래너를 회차당 한 번만 조회** — 2단계에서 받은 행 목록을 3·12단계가 재사용
2. **행 페이지는 대상 행만 열기** — 중복 판정은 속성만으로
3. **원고 본문을 대화에 출력하지 않기** — 삽입 도구 인자로 한 번만
4. 슬러그 중복 검사에 '이번 회차에 방금 기입한 슬러그'도 포함 (1번의 부수 조치)
5. 토큰을 아끼려고 지침·원고를 줄이지 말라는 안전장치 한 줄
6. **삭제**: "'썸네일'·'본문 이미지'(file) 속성은 자동화가 채울 수 없다" 줄.
   17:00 썸네일 루틴이 실제로 채우므로 사실이 아니게 됐고, 이 루틴에는 그 칸을
   채우라는 지시 자체가 없으며, 9단계가 이미 "이미지는 원고에서 다루지 않는다"고
   말하고 있어 중복이었습니다.

검토했지만 **넣지 않은 것**: 읽은 문서의 재출력 금지(규칙 준수에 영향 가능),
단계 순서 재배치(대기 행 소진 순서가 바뀜).

## 되돌리려면

`15-00-원고-자동화-v2.현재.txt` 를 루틴 프롬프트 칸에 통째로 붙여넣으면 됩니다.
루틴은 claude.ai UI에서 만들어져 에이전트가 고칠 수 없으므로, 사람이 직접 붙여넣어야 합니다.

## 20:00 색인 요청 루틴 (aside)

이 루틴은 저장소 코드가 아니라 aside(AI 브라우저)가 이선우 PC에서 돌립니다.
프롬프트 전문은 aside 안에 있어 여기에 없고, 덧붙일 규칙만 보관합니다.

`20-00-색인-요청-aside.추가규칙.txt` 는 이미 색인 요청이 끝나 있는 행을 다시
요청하지 않고 '색인 요청' 값만 '대기' → '완료'로 바꾸게 하는 규칙입니다.
스크린샷도 댓글도 남기지 않습니다. 단, 'URL이 Google에 등록되어 있음'만으로는
건너뛰지 않습니다 — 글을 고친 뒤 재색인을 받으려고 '완료'를 '대기'로 되돌려 둔
행이 그렇게 보이기 때문입니다.

팀 문서(노션 '운영 가이드 : 발행 URL 자동 색인 요청')는 2026-09-10 에 이 규칙에
맞춰 고쳐 뒀습니다 — 소개 콜아웃, 1-3 3단계, 1-3 아래 새 콜아웃, 2번 표 '완료'
의미, 5-2 절, 6번 문제 해결 표. 되돌릴 일이 생기면 노션 페이지 기록을 쓰세요.
